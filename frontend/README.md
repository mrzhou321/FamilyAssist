# FamilyAssister Frontend

React + Vite frontend for 家暖 FamilyAssister.

- `/mobile/`: family member PWA for quick notes, advice, memory browsing, and pairing.
- `/admin/`: admin console for members, memory review, pairing QR codes, and settings.
- `/`: redirects to `/mobile/`.

## Scripts

```bash
npm run dev
npm run build
npm run lint
```
